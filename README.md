# Cadence

Your habits, routines and days — in one rhythm. Fully offline, personal Android app.

## Stack
- Kotlin + Jetpack Compose (Material 3, Warm Paper theme)
- Room (on-device database — no accounts, no cloud)
- Built by GitHub Actions — every push to `main` produces a downloadable APK (see Releases)

## Roadmap
- **T1 — Foundation**: Today screen (habits + routines + tasks in one checklist), local DB, add/edit/complete/delete, bottom nav
- **T2 — Systems**: alarms, reminders, permissions, backup
- **T3 — Alive**: Kadie mascot, motion, haptics
- **T4 — Planner**: week/month, drag and drop
- **T5 — Insight**: stats, heatmaps, evening review
- **T6 — Notes**: full Keep-style notebook
- **T7 — Lockout**: aggressive app blocker
- **T8 — Modes**: DND/silent/bedtime + custom modes
- **T9 — Assistant**: talk to Kadie
- **T10 — Polish**: Material 3 expressive pass, v1.0 release

## Install
Download `app-debug.apk` from the latest Release, allow install from unknown sources, install.
